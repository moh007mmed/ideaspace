# IdeaSpace — النسخة الأولية

هذه نسخة أولية مجانية (MVP) للوحة أفكار مرئية تعمل دون مكتبات خارجية.

## الميزات الحالية
- مساحة يمكن تحريكها والتكبير/التصغير فيها.
- ملاحظات قابلة للسحب وتحرير النص.
- إضافة صور من الجهاز.
- رسم حر بالإصبع.
- ربط ملاحظتين بخط.
- حفظ محلي تلقائي في المتصفح.
- تصدير/استيراد ملف مشروع JSON.
- أساس PWA للتثبيت والعمل دون إنترنت بعد فتحها من رابط HTTPS مرة واحدة.

## حدود النسخة الأولى
- ليست لوحة لا نهائية رياضياً؛ المساحة كبيرة وقابلة للتحريك.
- الحفظ في المتصفح وليس في مجلد ملفات مستقل، وقد تمتلئ المساحة إذا أضيفت صور كبيرة.
- لا يوجد تصدير PDF/PNG بعد، ولا دعم عام لكل صيغ الملفات بعد.
- يجب استضافة الملفات على HTTPS كي يعمل Service Worker عادةً. فتح index.html مباشرة من مدير الملفات لا يفعّل وضع العمل دون إنترنت.
- اختبر التصدير والنسخ الاحتياطي قبل وضع ملاحظات مهمة.

## تشغيل مجاني من الهاتف
ارفع ملفات المجلد إلى مستودع GitHub، ثم فعّل Settings → Pages → Deploy from a branch → main / root. افتح رابط Pages على Chrome في Android، وانتظر تحميل الصفحة مرة واحدة، ثم من قائمة Chrome اختر Add to Home screen / Install app.

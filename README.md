# IdeaSpace v2 — نظام عناصر مستقل لكل نوع

تطبيق ويب تقدمي (PWA) مجاني، بلا مكتبات خارجية ولا حسابات ولا خادم. يعمل دون إنترنت بعد أول فتح.

## ما الذي تغيّر عن v1
- **كل نوع عنصر له شكله وأدواته**: نص (بلا خلفية)، ملاحظة لاصقة (ورقة ملوّنة)، شكل (SVG حقيقي: مستطيل/مستدير/بيضاوي/معين/مثلث)، عقدة خريطة ذهنية، صورة، ملف نصي. شريط الخصائص يعرض أدوات النوع المحدد فقط.
- **تخزين IndexedDB** بدل localStorage، مع ترحيل تلقائي لمشروع v3 القديم (المفتاح القديم لا يُحذف).
- **لوحة لا نهائية فعلاً**: لوحة الرسم بحجم الشاشة وتُرسم بحسب التحريك/التكبير (بدل 5000×5000 التي تستهلك ذاكرة هواتف Android الضعيفة).
- تحديد، تحريك، **تغيير الحجم**، قفل، تكرار، ترتيب أمام/خلف، حذف. تراجع/إعادة تشمل الكتابة والتحريك والحذف والحجم والرسم.
- روابط بأسهم تلتصق بحواف العناصر بأحجامها الحقيقية؛ فروع الخريطة الذهنية تنمو نحو اليسار (اتجاه القراءة العربي) مع رابط تلقائي؛ حذف الرابط بالضغط عليه.
- رسم بألوان وسماكتين وممحاة. قرص بإصبعين للتكبير والتحريك. زر ⌂ يعرض كل المحتوى، والضغط على نسبة التكبير يعيدها 100%.
- تصدير **JSON كامل (يشمل الصور)** و**SVG/PNG بشكل كل نوع** مع الصور. الصور تُصغَّر إلى 1600px لتخفيف الذاكرة.
- إصلاح أخطاء: فواصل الأسطر في الملفات النصية، تحديد موضع التكبير بعجلة الفأرة، ربط الأسهم بأحجام ثابتة خاطئة، غياب أيقونات PWA (كان يمنع «تثبيت التطبيق» على Android).
- أُزيل زر «PDF» لأنه كان يعرض تعليمات فقط.

## التشغيل والتثبيت
1. **انشر المجلد على HTTPS** (مثلاً GitHub Pages: ارفعه كمستودع `ideaspace` فيصبح `https://moh007mmed.github.io/ideaspace/`). الخدمة المساعدة (العمل دون إنترنت) تحتاج HTTPS أو localhost.
2. **Android**: افتح الرابط في Chrome مرة واحدة متصلاً ← ⋮ ← «تثبيت التطبيق» (أو «إضافة إلى الشاشة الرئيسية»). بعدها يعمل دون إنترنت.
3. **Windows**: افتح الرابط في Edge أو Chrome ← أيقونة التثبيت في شريط العنوان. للتجربة المحلية: `python -m http.server 8080` داخل المجلد ثم `http://localhost:8080`.
4. اختصارات Windows: Ctrl+Z تراجع، Ctrl+Y إعادة، Ctrl+D تكرار، Delete حذف، Esc إلغاء التحديد.

## الاستخدام
اضغط عنصراً لتحديده ← اضغطه ثانية لتحرير النص ← اسحب المقبض الدائري لتغيير الحجم. من «＋ فرع» على عقدة الخريطة تنشأ العقدة والرابط معاً.

## تحذيرات التخزين
البيانات على هذا الجهاز والمتصفح فقط؛ مسح بيانات الموقع قد يحذفها. يظهر تذكير بالنسخة الاحتياطية بعد 7 أيام. إن امتلأ التخزين تظهر رسالة «تعذّر الحفظ» فصدّر JSON فوراً.

## الاختبار
`tests/smoke.py` (Playwright + Chromium): 17 فحصاً — أنواع العناصر وأشكالها، التحريك، أدوات كل نوع، الفروع والروابط، الحفظ بعد إعادة الفتح، تصدير/استيراد JSON، ملف تالف، PNG، العمل دون إنترنت، ترحيل بيانات v3. **لم تُجرَّب النسخة بعد على هاتف Android فعلي أو بقلم إلكتروني**؛ جرّبها على جهازك قبل الاعتماد عليها.

## غير منفّذ بعد
تحديد متعدد، تدوير، جداول، بحث، قوالب، طيّ فروع الخريطة وإضافة شقيق، تسميات وأنواع الروابط، تصدير PDF وCSV/Markdown، معاينة الملفات (النصوص فقط كنص)، واجهة إنجليزية وLTR، وضع فاتح، شبكة/محاذاة، قص الصور، قائمة سياقية، مجموعات وطبقات، الكتابة اليدوية والتعرف على الأشكال.

## إضافة نوع عنصر جديد
أضف مدخلاً في `DEF` (أبعاده)، وفرعاً له في `render` (شكله)، وفي `bar` (أدواته)، وCSS بصنف `.it-<النوع>` — دون المساس بالأنواع الأخرى.

# IdeaSpace Full v1.0 — Mobile-first

تطبيق ويب تقدمي PWA مجاني، دون مكتبات خارجية أو حسابات سحابية. بيانات اللوحة تحفظ محلياً في `localStorage` على الجهاز والمتصفح الحالي.

## المزايا
- لوحة قابلة للتحريك والتكبير/التصغير باللمس المتعدد.
- ملاحظات وعناوين كبيرة وأشكال قابلة للكتابة.
- صور محلية، ملفات نصية TXT/MD/CSV كعناصر نصية.
- رسم حر، روابط بين العناصر، ألوان للملاحظات.
- حفظ محلي تلقائي.
- تراجع/إعادة أساسيان للعمليات التي تم تسجيلها.
- نسخة احتياطية JSON واستيراد مشروع JSON.
- تصدير SVG مبسط وPNG مبسط.
- PWA / service worker لفتح التطبيق دون إنترنت بعد فتحه مرة واحدة من HTTPS.

## مهم
- لا يوجد حساب أو تخزين سحابي. بيانات اللوحة محلية في متصفح الجهاز؛ مسح بيانات الموقع قد يمحوها. استخدم النسخ الاحتياطية.
- الصور الكبيرة قد تستهلك حصة التخزين المحلي. إذا امتلأت، صدّر نسخة JSON واحذف صوراً كبيرة.
- استيراد ملفات PDF/Office كمعاينة أصلية، تصدير PDF مباشر، الطبقات، التحديد المتعدد، والمحاذاة الذكية ليست ضمن هذه النسخة.
- SVG وPNG مبسطان ولا يحفظان الصورة المضمنة كصورة كاملة؛ استخدم JSON للاحتفاظ بالمشروع والصور.
- هذه نسخة عملية أولية موسعة وليست منتجاً مختبراً بالكامل. اختبرها قبل الاعتماد عليها للبيانات المهمة.
- لكي يعمل PWA/offline يجب نشره عبر HTTPS مثل GitHub Pages. فتح index.html من مدير الملفات لا يفعّل Service Worker.
